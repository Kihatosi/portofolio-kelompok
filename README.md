## 1. Latar Belakang & Tujuan
Proyek ini mengukur dan membandingkan performa dua pendekatan algoritma berdasarkan dataset empiris terukur.

## 2. Metrik Pengukuran
- **Input Size**: Jumlah data uji (1,000 - 10,000 baris).
- **Execution Time (ms)**: Kecepatan proses eksekusi.
- **Accuracy (%)**: Tingkat ketepatan hasil.
